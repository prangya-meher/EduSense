# Features of Java
## a) Platform Independent

Normally, programming languages convert source code directly into machine code.

Machine code depends on the operating system.

Java works differently:

Java source code is converted into bytecode.
Bytecode runs inside JVM.
JVM converts it into machine code according to the operating system.

Because every OS has its own JVM, the same Java program works everywhere.

Flow of Execution

Source Code (.java)→Bytecode (.class)→JVM→Machine Code

## b) Object-Oriented

Java follows Object-Oriented Programming principles.

Everything in Java is organized using:

Classes
Objects

OOP helps:

Organize large programs
Reuse code
Improve security
Reduce complexity

Main OOP concepts:

Encapsulation
Inheritance
Polymorphism
Abstraction
## c) Simple

Java is considered simpler than languages like C++ because:

No pointers
Automatic memory management
Easy syntax
Built-in libraries

### Example:

System.out.println("Hello");

## d) Secure

Java is secure because:

No direct memory access
Bytecode verification
Automatic garbage collection
Exception handling

Java is commonly used in:

Banking systems
Online transactions
Enterprise applications
## e) Robust

Robust means strong and reliable.

Java prevents many errors using:

Strong type checking
Exception handling
Memory management
Garbage collection
## f) Multithreaded

A thread is a small unit of execution.

Java supports multiple threads running simultaneously.

### Example:

Playing music while downloading files.

Benefits:

Better performance
Faster execution
Efficient CPU usage
## g) Distributed

Distributed means applications can work across multiple systems connected through a network.

Java supports:

Internet-based applications
Client-server architecture
Distributed computing
