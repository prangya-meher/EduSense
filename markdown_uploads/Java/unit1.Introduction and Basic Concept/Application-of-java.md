# Applications of Java

Java is used in many fields because it is secure and platform independent.

## a) Web Applications

Java is used for:

Backend development
Enterprise web applications

Frameworks:

Spring
Hibernate

### Examples:

Banking websites
E-commerce platforms

## b) Mobile Applications

Android apps are mainly developed using Java.

### Example:

Android Studio supports Java.
## c) Desktop Applications

Java can create GUI applications using:

AWT
Swing
JavaFX

### Examples:

Calculator
Text editor
## d) Enterprise Applications

Large business applications use Java because it is:

Secure
Scalable
Reliable

### Examples:

Banking systems
Hospital management systems
## e) Scientific Applications

Java is used where:

High accuracy
Stability
Security

are important.
