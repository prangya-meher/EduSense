# Variables in Java
## What is Variable?

A variable is a memory container used to store data.

### Example:

int age = 20;

Here:

int → data type
age → variable name
20 → value
Why Variables are Needed

Programs process data.

Variables store:

Numbers
Characters
Text
Boolean values
Variable Declaration

### Syntax:

datatype variableName;

### Example:

int marks;
Variable Initialization

Assigning value:

marks = 90;
Combined Form
int marks = 90;


# Data Types in Java

Data type defines:

Type of data
Size of memory
Types of Data Types
### 1. Primitive Data Types

Built-in types.

### 2. Non-Primitive Data Types

Created by programmer.

Example:

Arrays
Classes
Strings
Primitive Data Types
Type	Size	Stores
byte	1 byte	Small integers
short	2 bytes	Integers
int	4 bytes	Whole numbers
long	8 bytes	Large integers
float	4 bytes	Decimal values
double	8 bytes	Large decimal values
char	2 bytes	Single character
boolean	1 bit	true/false
Example
int age = 21;
double salary = 25000.50;
char grade = 'A';
boolean result = true;

# Operators in Java

Operators perform operations on data.

### a) Arithmetic Operators

Used for mathematical operations.

Operator	Operation
+	Addition
-	Subtraction
*	Multiplication
/	Division
%	Modulus
Example
int a = 10;
int b = 5;

System.out.println(a + b);
System.out.println(a - b);
### b) Relational Operators

Used for comparisons.

Result:

true
false
Operator	Meaning
==	Equal
!=	Not equal
>	Greater
<	Less
>=	Greater equal
<=	Less equal
### c) Logical Operators

Used with conditions.

Operator	Meaning
&&	AND
||	OR
!	NOT
### d) Assignment Operators

Used for assigning values.

Operator	Meaning
=	Assign
+=	Add and assign
-=	Subtract and assign
